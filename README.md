# Практична робота №4 — локальна авторизація MVC

Окремий простий проєкт: реєстрація, вхід, профіль користувача та вихід із сесії. Код використовує одну модель `User` і звичайні цикли для пошуку акаунта.

## Запуск

Відкрий `MvcAuthPractice.slnx` у Visual Studio та натисни **F5**. Першою відкриється сторінка реєстрації.

Акаунти зберігаються тільки в пам'яті процесу, тому після зупинки програми видаляються. Це навчальний приклад — не використовуй справжній пароль.
